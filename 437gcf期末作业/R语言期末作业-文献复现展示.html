文献复现报告

复现对象：Ohtsubo 等 (2014)《It's the attention that counts: interpersonal attention fosters intimacy and social exchange》

数据来源：原论文公开数据集 1-s2.0-S1090513814000245-mmc1.xlsx

复现环境：R 4.5.2 + 核心包 lme4 / lavaan / BayesFactor

复现方法：① 严格遵循原文统计流程的验证性复现；② 采用现代统计方法的探索性复现

报告日期：2026 年 6 月 11 日

摘要

本文对 Ohtsubo 等 (2014) 提出的"人际注意力作为长期伙伴关系承诺线索"理论进行了验证性与探索性复现。利用原论文公开数据集，在 R 环境下严格复现了原研究的方差分析、中介效应检验及 t 检验，并进一步采用线性混合效应模型、Bootstrap 稳健推断、贝叶斯 ANOVA 及链式中介模型进行探索性分析。验证性复现结果显示，超过 90% 的关键统计量与原文完全或高度一致，注意力对亲密感的促进作用独立于物质获益，且亲密感完全中介了注意力对社会交换意愿的影响。探索性复现支持了上述核心结论的稳健性，但研究 2c 的注意力剂量–反应关系在异方差稳健检验及贝叶斯分析中不再显著，提示原结论可能受小样本与量表低信度影响。本研究证实了该理论框架的可重复性，同时建议对剂量效应结论持谨慎态度。

一、原文实验设计概述

本研究旨在解决进化心理学领域的 "友谊悖论"——人类友谊关系中的合作行为表现出比标准一报还一报 (TFT) 策略更高的慷慨度。研究者提出人际注意力是个体区分长期忠诚伙伴与机会主义伙伴的核心评估线索的核心假设。通过 5 项递进式实验，研究系统分离了 "注意力投入" 与 "实际物质获益" 的混淆效应，验证了人际注意力对亲密感形成的独立因果作用。

1.1 研究 1：情境实验（分离注意力与即时获益）

  • 研究 1a（N = 309）：采用 2 (注意力：存在 / 缺失) × 2 (获益：存在 / 缺失) × 2 (时间投入：长 / 短) × 3 (场景顺序) 被试间因子设计
    • 实验场景：构建建议寻求、生日惊喜、学业支持三种日常社会支持情境
    • 变量操纵：注意力通过 "对方是否主动感知并关注你的状态" 操纵；获益通过 "对方的帮助是否有效解决问题" 操纵
    • 因变量：亲密感（包含理解、接纳、关心三个维度）、对伴侣未来帮助的预期、帮助伴侣的意愿
  • 研究 1b（N = 105）：剔除研究 1a 中无显著效应的 "时间投入" 变量，对核心结果进行独立样本重复验证

1.2 研究 2：实验室实验（完全分离注意力与任何潜在获益）

采用计算机模拟双人合作任务范式，被试被随机分配为 "玩家 2" 角色，搭档（实为计算机程序）为 "玩家 1" 角色。核心操纵为：搭档可实时监控被试的答题进度（注意力操作），但实验规则明确禁止搭档提供任何形式的帮助（无获益可能），监控状态通过屏幕信号灯颜色变化向被试呈现。

  • 研究 2a（N = 29）：比较 "80% 时间被监控" 与 "0% 时间被监控" 两组被试的亲密感差异
  • 研究 2b（N = 44）：针对研究 2a 对照组可能存在的负向偏差问题，设置 "系统随机信号灯" 作为中性控制条件（信号出现频率同为 80%，但非搭档主动控制）
  • 研究 2c（N = 36）：检验注意力的剂量–反应关系，设置低 (20%)、中 (50%)、高 (80%) 三个注意力频率水平组

二、原文证据链与核心结论

2.1 原文证据链

  1. 理论基础：传统互惠利他理论无法解释友谊关系的非条件性特征；生物市场理论指出，个体需要可靠线索评估伴侣的长期关系承诺意愿
  2. 核心假设：注意力作为有限认知资源，其分配比例直接反映个体对关系的主观价值评估，因此可作为承诺的可信信号
  3. 递进式验证逻辑：
    • 研究 1 证明：注意力对亲密感的影响独立于即时物质获益，且效应量显著大于获益的效应
    • 中介分析表明：亲密感完全中介了注意力对 "帮助预期" 和 "帮助意愿" 的影响
    • 研究 2a–2b 证明：纯粹的主动注意力投入（无任何物质获益可能）即可显著提升亲密感
    • 研究 2c 表明：亲密感与注意力频率之间存在正相关剂量–反应关系

2.2 原文核心结论

  1. 人际注意力是促进亲密感形成的核心因素，其作用不依赖于是否带来实际物质利益
  2. 亲密感是连接注意力投入与后续社会交换行为的近端心理机制
  3. 友谊进化理论模型必须纳入 "关系价值信息交换" 维度，而非仅关注物质成本与收益的交换

# 自定义函数：自动生成符合学术规范的Markdown三线表
md_table <- function(df, digits = 3) {
  nc <- ncol(df)
  cn <- colnames(df)
  cat("|", paste(cn, collapse = " | "), "|\n")
  cat("|", paste(rep("---", nc), collapse = " | "), "|\n")
  for (r in seq_len(nrow(df))) {
    vals <- sapply(seq_len(nc), function(j) {
      v <- df[r, j]
      if (is.numeric(v)) sprintf(paste0("%.", digits, "f"), v)
      else as.character(v)
    })
    cat("|", paste(vals, collapse = " | "), "|\n")
  }
  cat("\n")
}

核心概念说明：

  • # 标识注释行：仅用于代码说明，不被 R 解释器执行
  • 代码执行顺序：严格从上至下逐行执行
  • 随机种子的重要性：统计分析中的 Bootstrap 抽样、贝叶斯 MCMC 采样等过程依赖随机数生成，设定固定种子可确保不同研究者、不同时间运行相同代码得到完全一致的结果

原始数据通常存在格式不规范、变量类型错误、缺失值等问题，预处理是保证分析结果有效性的前提。

核心概念说明：

  • 因子类型：R 中用于表示分类变量的数据类型，确保统计分析将其作为类别而非连续数值处理

  • 管道符 %>%：将前一个函数的输出作为后一个函数的输入，提高代码可读性

4.2.2 线性混合效应模型拟合

传统方差分析要求所有观测相互独立，但本研究中同一被试完成了 3 个场景的任务，其多次观测存在非独立性。混合效应模型通过引入随机效应项，有效解决了这一问题。

# 拟合线性混合效应模型
m_intimacy_1a <- lmer(
  intimacy ~ attention * benefit * scenario + time + Order +
    (1 | ID),          # 随机效应：允许截距随被试ID变化
  data = dl_1a,
  REML = FALSE         # 使用ML估计，便于模型比较
)

anova(m_intimacy_1a, type = "III")  # Type III平方和

# 计算模型解释力：Nakagawa & Schielzeth (2013) R²
r2_nakagawa(m_intimacy_1a)
# R²m：边际R²，仅由固定效应解释的方差比例
# R²c：条件R²，由固定效应和随机效应共同解释的方差比例

核心概念说明：

  • 固定效应：研究者感兴趣的、系统的实验操纵效应（如注意力、获益的影响）
  • 随机效应：由抽样产生的、非系统性的变异（如不同被试之间的个体差异）
  • Type III 平方和：在不平衡设计中，每个效应的检验控制了其他所有效应的影响

4.2.3 链式中介效应分析

中介分析旨在揭示自变量对因变量产生影响的内在机制。链式中介模型用于检验包含多个连续中介变量的复杂传导路径。

# 定义链式中介模型（lavaan语法）
model5 <- "
  intimacy ~ a5*att_num + b1 + t1 + male + sc_surprise + sc_moral + ord2 + ord3
  will_help ~ d51*intimacy + a52*att_num + b1 + t1 + male + sc_surprise + sc_moral + ord2 + ord3
  exp_help ~ d52*will_help + d53*intimacy + c5*att_num + b1 + t1 + male + sc_surprise + sc_moral + ord2 + ord3

  # 定义特定间接效应
  ind_att_int_will := a5*d51          # 注意力→亲密感→帮助意愿
  ind_att_int_exp := a5*d53           # 注意力→亲密感→帮助预期
  ind_att_will_exp := a52*d52         # 注意力→帮助意愿→帮助预期
  ind_serial := a5*d51*d52            # 链式间接效应
  total_ind := ind_att_int_will + ind_att_int_exp + ind_att_will_exp + ind_serial
  total := c5 + total_ind
"

fit5 <- sem(model5, data = dl_1a_med, cluster = "ID")
parameterEstimates(fit5)

核心概念说明：

  • 中介效应：自变量通过一个或多个中间变量对因变量产生的间接影响
  • 完全中介：自变量对因变量的直接效应不显著，所有影响均通过中介变量传递
  • 聚类稳健标准误：当数据存在聚类结构时，修正标准误估计偏差

4.3 研究 2a–2b：Bootstrap 稳健 t 检验

研究 2 为两组被试间设计，采用 t 检验比较组间差异。传统 t 检验依赖正态性和方差齐性假设，在小样本情况下可能产生偏差。Bootstrap 方法通过有放回的重复抽样构建经验抽样分布，无需依赖分布假设，具有更稳健的统计性质。

# 自定义Bootstrap t检验函数
bootstrap_t_test <- function(data, dv_name, R = 5000) {
  g1 <- data[[dv_name]][data$attention == "a1"] # 注意力组
  g0 <- data[[dv_name]][data$attention == "a0"] # 对照组

  ott <- t.test(g1, g0, var.equal = FALSE)   # Welch t检验
  ot <- as.numeric(ott$statistic)             # 观测t值
  omd <- mean(g1) - mean(g0)                  # 观测组间均值差

  dr <- effectsize::cohens_d(g1, g0)         # Cohen's d效应量
  od <- as.numeric(dr$Cohens_d)
  dcl <- as.numeric(dr$CI_low)
  dch <- as.numeric(dr$CI_high)

  # Bootstrap置换检验
  dc <- data
  grand_mean <- mean(data[[dv_name]])
  dc[[dv_name]][data$attention == "a1"] <- g1 - mean(g1) + grand_mean
  dc[[dv_name]][data$attention == "a0"] <- g0 - mean(g0) + grand_mean

  btn <- function(data, indices) {
    d <- data[indices, ]
    g1_boot <- d[[dv_name]][d$attention == "a1"]
    g0_boot <- d[[dv_name]][d$attention == "a0"]
    if (length(g1_boot) < 2 || length(g0_boot) < 2) return(NA)
    as.numeric(t.test(g1_boot, g0_boot, var.equal = FALSE)$statistic)
  }

  set.seed(2024)
  btr <- boot::boot(dc, btn, R = R)
  btv <- btr$t[!is.na(btr$t)]
  pb <- mean(abs(btv) >= abs(ot))           # Bootstrap p值

  return(data.frame(
    DV = dv_name, N_a1 = length(g1), N_a0 = length(g0),
    Mean_a1 = mean(g1), Mean_a0 = mean(g0), MeanDiff = omd,
    t = ot, df = as.numeric(ott$parameter), Welch_p = ott$p.value,
    Boot_p = pb, Cohens_d = od, d_CI_low = dcl, d_CI_high = dch
  ))
}

核心概念说明：

  • 效应量：量化变量之间关系强度的指标，不受样本量影响。Cohen's d 的常用标准为：d = 0.2（小效应）、d = 0.5（中等效应）、d = 0.8（大效应）
  • 置换检验：一种非参数统计方法，通过随机置换数据来生成零假设分布，无需假设数据服从特定分布

4.4 研究 2c：贝叶斯 ANOVA 与剂量–反应分析

研究 2c 为三组被试间设计，原文采用普通单因素 ANOVA，但存在样本量小、方差不齐、量表信度低等问题。贝叶斯方法直接量化不同假设的证据强度，提供更稳健的推断。

# 1. 贝叶斯方差分析
set.seed(2024)
bf_full <- anovaBF(intimacy ~ attention, data = df_2c, iterations = 10000)
bf10_val <- as.numeric(extractBF(bf_full)["bf"])

# BF₁₀解读标准（Jeffreys, 1961）：
# BF₁₀ > 10：强证据支持H1
# 3 < BF₁₀ < 10：中等证据支持H1
# 1/3 < BF₁₀ < 3：证据不足，无法判断
# BF₁₀ < 1/3：中等证据支持H0
# BF₁₀ < 1/10：强证据支持H0

# 2. 稳健回归：检验注意力与亲密感的剂量-反应关系
df_2c$att_prob <- dplyr::case_when(
  df_2c$attention == "Low(20%)"  ~ 0.2,
  df_2c$attention == "Mid(50%)"  ~ 0.5,
  df_2c$attention == "High(80%)" ~ 0.8
)

# M估计稳健回归：对异常值和非正态分布具有鲁棒性
rob_fit <- MASS::rlm(intimacy ~ att_prob, data = df_2c)
coef_b <- coef(rob_fit)["att_prob"]
se_b <- sqrt(diag(vcov(rob_fit)))["att_prob"]
t_b <- coef_b / se_b
p_b <- 2 * pt(abs(t_b), df = nrow(df_2c) - 2, lower.tail = FALSE)

核心概念说明：

  • 贝叶斯因子：贝叶斯假设检验的核心指标，直接回答 "数据支持哪个假设" 的问题
  • 稳健回归：采用 M 估计方法，通过降低异常值的权重来减少其对回归结果的影响

六、结论差异与讨论

6.1 得到稳健支持的原文结论

  1. ✅ 人际注意力对亲密感的影响独立于即时物质获益，且其效应量显著大于获益的效应
  2. ✅ 亲密感完全中介了注意力投入对后续社会交换意愿的影响
  3. ✅ 纯粹的主动注意力投入（无任何物质获益可能）即可显著提升人际亲密感
  4. ✅ 个体能够准确感知他人的注意力分配频率

6.2 存在争议的原文结论

  1. ❌ 注意力剂量效应未得到稳健支持：研究 2c 的结果在采用异方差稳健方法和贝叶斯分析后完全不显著，且量表信度问题严重削弱了其结论的内部效度
  2. ⚠️ 获益对亲密感的影响被原文高估：混合效应模型分析显示，获益的效应量更小、显著性更低，进一步支持了注意力在亲密感形成中的主导作用

6.3 复现研究的启示

  1. 原研究的核心结论具有很强的统计稳健性，即使采用更严格的现代统计方法仍得到一致支持
  2. 研究 2c 的剂量效应结论需要谨慎对待，未来研究需采用更大样本量和更可靠的测量工具进行验证
  3. 对于重复测量设计，混合效应模型优于传统聚合数据的方差分析，能够提供更准确的效应量估计和更可靠的统计推断

七、研究局限性

  1. 所有被试均为日本在校大学生，样本同质性较高，研究结果的文化普适性有待检验
  2. 研究 2 采用陌生人短暂互动范式，与真实长期友谊关系的形成过程存在差异
  3. 所有因变量均采用自我报告法测量，缺乏客观行为指标的验证
